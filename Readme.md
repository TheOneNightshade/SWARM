

# SWARM has moved to production

SWARM, the Android wardriving app that links a swarm of ESP32 nodes to your phone and maps Wi-Fi, Bluetooth and cell live as you drive, is now a full release.

**The latest version is available on itch.io:**
https://theonenightshade.itch.io/swarm-by-nightshade

Buy once and you get every future update.

## Getting started
1. Buy and download SWARM from the itch.io page above.
2. Flash your nodes in your browser with the SWARM Node Flasher: https://theonenightshade.github.io/SWARM-Node-Flasher
3. Open SWARM, connect your nodes and start driving.

## Older builds
Builds previously posted here are no longer updated or supported. Please switch to the itch.io release for the newest features and fixes.
